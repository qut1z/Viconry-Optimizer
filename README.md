
          VICONRY ABSOLUTE OPTIMIZER v5.0

ОПИСАНИЕ:
Программа для мгновенной настройки графики Minecraft. 
Поддерживает: Vanilla, OptiFine, Sodium, Sodium Extra.

ВАЖНО:
Программа написана на Python с использованием ИИ (Gemini). 
Ввиду специфики сборки, антивирус может ложно срабатывать 
на файл. Добавьте его в исключения — программа работает 
только с файлами настроек игры.

КАК ПОЛЬЗОВАТЬСЯ:
1. Закройте Minecraft перед использованием.
2. Запустите ViconryOptimizer.exe.
3. В поле "ПАПКА INSTANCES" укажите путь к вашим сборкам.
   (Обычно для Prism Launcher это: AppData\Roaming\PrismLauncher\instances)
4. Выберите нужную сборку в выпадающем списке.
5. Нажмите одну из кнопок:
   - [MIN]: Если лагает. Сделает графику минимальной.
   - [BASE]: Стандартные настройки.
   - [MAX]: Для мощных ПК (включает всё на полную).
6. Запускайте игру и наслаждайтесь!

ДОПОЛНИТЕЛЬНО:
- Кнопка "СОХРАНИТЬ": создает файл-бекап ваших текущих 
  настроек (всех 4-х конфигов сразу).
- Кнопка "ЗАГРУЗИТЬ": позволяет вернуть ваши сохраненные 
  настройки на любой другой сборке.
